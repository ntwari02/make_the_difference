# Authentication Service Components

This directory contains components for authentication features including:

## Components:
- Login forms and components
- Registration forms and components
- Password reset components
- Security questions components
- Profile management components
- Role-based access components

## Backend Services:
- `/server/controllers/auth.controller.js`
- `/server/controllers/passwordReset.controller.js`
- `/server/controllers/securityQuestions.controller.js`
- `/server/services/auth.service.js`
- `/server/services/securityQuestions.service.js`
