# E-learning Service Components

This directory contains components for e-learning features including:

## Subdirectories:
- **courses/**: Course listing, creation, and management components
- **modules/**: Course module components
- **lessons/**: Lesson components and video players
- **quiz/**: Quiz and assessment components
- **certificates/**: Certificate generation and display components
- **online-classes/**: Live class components
- **organizations/**: Organization management components

## Backend Services:
- `/server/elearning/controllers/elearning.controller.js`
- `/server/elearning/controllers/quiz.controller.js`
- `/server/elearning/controllers/certificate.controller.js`
- `/server/elearning/controllers/online-classes.controller.js`
- `/server/elearning/controllers/org.controller.js`
