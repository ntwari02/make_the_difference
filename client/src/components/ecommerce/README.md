# E-commerce Service Components

This directory contains components for e-commerce features including:

## Subdirectories:
- **cars/**: Car listing, details, and management components
- **spare-parts/**: Spare parts catalog and management components
- **payments/**: Payment processing and transaction components
- **search/**: Advanced search and filtering components
- **recommendations/**: Recommendation engine components

## Backend Services:
- `/server/ecommerce/controllers/cars.controller.js`
- `/server/ecommerce/controllers/spare-parts.controller.js`
- `/server/ecommerce/controllers/payment.controller.js`
- `/server/ecommerce/controllers/advanced-search.controller.js`
- `/server/ecommerce/controllers/recommendations.controller.js`
