# Seller Checklist

This checklist helps individual sellers complete setup and successfully list vehicles. It is organized by three areas: Workspace, Inventory, and Create Listing.

## 1) Workspace

Goal: Ensure your seller account, profile, and workspace settings are properly configured.

- Account & Access
  - Confirm you are registered and can log in.
  - Set up two-factor authentication if available.
  - Verify your email and phone number.

- Profile & Organization
  - Complete profile info (name, business name if applicable, address, time zone).
  - Upload profile photo and business logo.
  - Add payment details for payouts and confirm tax information (e.g., W-9/EIN if applicable).

- Notifications & Preferences
  - Configure notification preferences (messages, offers, sales, reviews).
  - Set communication channels (email, SMS, in-app).
  - Opt in/out of marketing announcements.

- Security
  - Update a strong password.
  - Set security questions (if enabled).
  - Review active sessions/devices and sign out unused ones.

- Workspace Navigation Familiarity
  - Dashboard: Review quick stats (views, messages, saved cars, offers).
  - Messages: Ensure you can read/respond to inquiries.
  - Payments: Confirm you can view payouts, fees, and history.
  - Reviews: Monitor feedback and respond professionally.
  - Settings: Confirm locale, currency, date/time format.

## 2) Inventory (SellerInventory)

Goal: Prepare and maintain your inventory records so they are complete, accurate, and searchable.

- Actions & Views
  - Filters: search by title/make/model; filter by status (All, active, draft, pending, sold, rejected).
  - Counts: view chips for Total, Active, Draft, Pending, Sold.
  - Views: toggle Cards/Table view.
  - Row actions: View listing, Edit listing.
  - Bulk actions: Mark Draft, Publish, Delete (requires selecting rows/cards).
  - Export: export current (filtered or selected) rows to CSV.
  - Refresh: reload inventory from the server.
  - Add Vehicle: navigate to Create Listing.

- Inventory Setup
  - Decide which vehicles you will sell and gather VINs.
  - Prepare high-quality photos and short videos (landscape preferred, good lighting).
  - Collect documents: title status, maintenance records, CARFAX/AutoCheck (if available).

- Vehicle Data Completeness
  - Required info per vehicle: make, model, year, trim, mileage, transmission, drive type, fuel type, color (exterior/interior), VIN.
  - Pricing: set list price and acceptable negotiation range.
  - Condition: describe wear/tear, recent service, accidents, modifications.
  - Location: city/state and pickup details.
  - Availability: ready-to-sell date and test-drive availability window.

- Media Standards
  - Minimum 8–15 exterior/interior photos (front/rear, sides, wheels, dashboard, seats, odometer, engine bay, trunk).
  - Include close-ups of any blemishes for transparency.
  - Optional: 15–60s walkaround video.

- Compliance & Accuracy
  - Confirm VIN matches photos and documentation.
  - Disclose known issues to reduce disputes/returns.
  - Ensure pricing complies with local regulations and platform policies.

- Inventory Maintenance
  - Archive or mark sold vehicles promptly.
  - Update price and availability weekly.
  - Refresh photos if vehicle condition changes.
  - Keep statuses accurate: use Draft while editing; Publish once finalized; track Pending/Rejected per platform flow.

## 3) Create Listing (SellerAddCar)

Goal: Publish polished, trustworthy listings that convert.

- Form Structure (exact fields)
  - Title: `Listing title`.
  - Make: select one of ['Toyota','Honda','Ford','BMW','Mercedes','Nissan','Hyundai','Kia','Volkswagen','Audi'].
  - Model: free text.
  - Year: number (min 1960, max current year + 1).
  - Mileage (km): number.
  - Transmission: select ['Automatic','Manual'].
  - Fuel: select ['Petrol','Diesel','Hybrid','Electric'].
  - Drivetrain: select ['FWD','RWD','AWD'].
  - Price (USD): number.
  - Location: free text (City, Country).
  - Price negotiable: switch.
  - Description: multiline details.
  - Images: add up to 10 (preview only until save).
  - Features: chips from presets (Sunroof, Leather seats, Bluetooth, Backup camera, Heated seats, Apple CarPlay, Android Auto, Navigation) and removable.

- Drafts & Autosave
  - Draft auto-saves to browser storage while editing; use Reset to clear.
  - You can export your draft as JSON or CSV.

- Basic Details
  - Enter VIN (auto-fill where supported) and confirm decoded fields.
  - Complete all required fields; avoid placeholders.

- Pricing & Fees
  - Set competitive listing price (research comparable listings).
  - Add optional discounts (seasonal, cash, quick-sale) if desired.
  - Review platform fees/commissions and net payout estimate.

- Description
  - Write a clear, honest description: ownership history, maintenance, features, why selling.
  - Highlight unique value (e.g., one-owner, new tires, warranty, service records).
  - Include call to action for test drives or questions.

- Photos & Media
  - Upload media following the Inventory Media Standards.
  - Reorder gallery to show the best hero image first.
  - Add short captions if helpful (e.g., "New brakes Aug 2025").

- Vehicle Features & Options
  - Select packages, safety tech, infotainment, and driver-assist features.
  - Indicate any aftermarket upgrades and original parts availability.

- Condition & Disclosures
  - Provide known issues and recent repairs.
  - Attach reports (CARFAX/AutoCheck) if available.
  - Add warranty info (factory, extended, none) and coverage terms.

- Logistics
  - Specify pickup location and preferred meeting spots.
  - Offer delivery/shipping options if supported; include cost estimate.
  - Define availability window for viewings/test drives.

- Policies
  - Set test-drive requirements (valid license, insurance proof, refundable deposit if required).
  - Set hold policy (e.g., 24–48 hour hold with deposit).
  - Return/refund terms if applicable.

- Save, Preview & Publish
  - Use in-page Preview panel to confirm specs, price, photos, and features.
  - Use Print to generate a printable preview or save as PDF.
  - Click Save Listing when valid; you will be redirected back to Inventory.
  - Preview the listing: check typos, image order, price, and disclosures.
  - Verify calculator-estimated monthly payment (if shown) looks reasonable.
  - Publish and confirm the listing appears under your Inventory and search results.

## Post-Publish Checklist

- Promotion
  - Share the listing link on social media or local groups.
  - Enable promotional boosts if offered by the platform.

- Responsiveness
  - Respond to messages within 24 hours.
  - Use saved replies for common questions (availability, price, location).

- Optimization
  - After 7–10 days, assess views/contacts; adjust price or media if low engagement.
  - Update title/first photo to improve click-through if impressions are high but clicks are low.

## Quick References

- Workspace: Profile, Payments, Notifications, Security.
- Inventory: Data completeness, accurate disclosures, quality media, weekly updates.
- Create Listing: Full details, honest description, strong hero image, publish, monitor.

## 4) Insights / Analytics (SellerAnalytics)

Goal: Monitor performance, understand channels and regions, and export data.

- Controls
  - Period: choose Last 12 months, 6 months, or 3 months.
  - Date filters: optional Start date and End date; Clear dates resets.
  - Export CSV: download KPIs and chart/summary data.

- KPIs
  - Total Revenue, Total Sales, Avg Order Value (AOV).

- Charts & Tables
  - Revenue & Sales over time (line chart).
  - Sales by Channel (vertical bar chart).
  - Top Selling Models (table with model, units, revenue).
  - Sales by Location (table with region and revenue).
  - Conversion Rate (gauge-like pie; Leads to Sales %).

- Best Practices
  - Track period-over-period trends, identify seasonality.
  - Use channel insights to focus promotion where it performs best.
  - Export data monthly for bookkeeping and analysis.

## 5) Messages (SellerMessages)

Goal: Triage buyer inquiries, negotiate offers, and maintain fast response times.

- Layout
  - Folders: Inbox, Archived, Sent, with unread count badge.
  - Toolbar: select all/none, search, category filter, mark as read, delete.
  - List: sender, subject, category (inquiry/offer/complaint/support), priority (low/normal/high), timestamp.
  - Detail: full message, reply editor, send/cancel.

- Workflow
  - Use search to find conversations by subject or sender name.
  - Filter by category to focus on offers or support.
  - Bulk-select to mark read or delete.
  - Reply promptly; keep messages professional and concise.

- SLAs & Tips
  - Aim to reply within 24 hours; faster responses increase conversions.
  - Save common replies for availability, pricing, and location.

## 6) Reviews (SellerReviews)

Goal: Build trust by engaging with feedback and highlighting good experiences.

- Overview
  - Average rating, total reviews; rating distribution visualization.
  - Filters: by rating, search by buyer name/comment, sort (Newest, Oldest, Most helpful, Highest rating).
  - Pagination: navigate through reviews; Export CSV of the current filtered list.

- Engaging with Reviews
  - Reply to both positive and negative feedback politely and constructively.
  - Thank buyers for positive reviews; address issues with clear next steps.
  - Highlight verified purchases and helpful votes in your marketing.

- Maintenance
  - Review weekly; track recurring themes to improve operations.
  - Use insights to adjust listings, pricing, and communication.


## 7) Payouts / Payments (SellerPayments)

Goal: Track transactions, fees, and net payouts; export records.

- Controls
  - Search: by buyer name, vehicle make, or transaction ID.
  - Status filter: All, Completed, Pending, Failed, Refunded.
  - Export: download current view.

- Summary KPIs
  - Total Earnings: sum of net amounts for completed transactions.
  - Pending: net amount for pending transactions.
  - Completed: count of completed transactions.
  - Platform Fee: reference indicator (e.g., 3%).

- Transaction Table Columns
  - Transaction ID, Buyer, Vehicle, Amount, Fee, Net, Method (Credit Card/Bank Transfer/PayPal/Cash), Status, Date.

- Best Practices
  - Reconcile payouts weekly; match Net to your bank deposits.
  - Filter by Pending to monitor expected payouts.
  - Export at month-end for accounting and taxes.

## 8) Settings (SellerSettings)

Goal: Configure notifications, privacy, preferences, appearance, and account controls.

- Notification Preferences
  - Email: enable/disable; granular toggles for New buyer inquiries, New purchase offers, Payment updates.
  - Push: enable/disable; granular toggle for Review replies.

- Privacy & Visibility
  - Show profile publicly, Show contact information, Show listings publicly, Allow buyer messages.

- Preferences
  - Language, Timezone, Currency.
  - Auto-refresh dashboard data toggle.

- Appearance
  - Light/Dark mode toggle.

- Danger Zone
  - Delete account: irreversible; understand impacts (listings, profile info, transactions, reviews).
