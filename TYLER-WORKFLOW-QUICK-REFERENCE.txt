🌿 TYLER BRANCH WORKFLOW - Quick Reference

═══════════════════════════════════════════════════════════════

🎯 YOUR NEW WORKFLOW (Instead of 4 manual commands):

❌ OLD WAY (Caused errors):
   git checkout Tyler
   git pull origin Tyler  
   git checkout "sam's"
   git merge Tyler

✅ NEW WAY (Zero errors):
   merge-tyler-changes.bat

═══════════════════════════════════════════════════════════════

🚀 QUICK COMMANDS:

📥 When Tyler has new changes:
   merge-tyler-changes.bat

🔄 Switch to Tyler branch:
   switch-to-tyler.bat

🔄 Switch back to your branch:
   switch-to-sam.bat

🛠️ Server management:
   cd server && npm start     - Start server
   cd server && npm run dev   - Start with auto-restart
   cd server && kill-server.bat - Kill server

═══════════════════════════════════════════════════════════════

📋 WHAT HAPPENS NOW:

1. You run: merge-tyler-changes.bat
2. Script stops server automatically
3. Script saves your changes
4. Script switches to Tyler branch
5. Script pulls Tyler changes
6. Script switches back to "sam's"
7. Script merges Tyler changes
8. Script restores your changes
9. Script asks if you want to start server
10. You choose: Start server or start later

✅ RESULT: Zero EADDRINUSE errors!

═══════════════════════════════════════════════════════════════

🚨 EMERGENCY (If still getting errors):
   cd server
   kill-server.bat
   npm start

═══════════════════════════════════════════════════════════════

💡 PRO TIPS:
- Always use the scripts instead of manual git commands
- Use npm run dev for development (auto-restart)
- The scripts handle everything automatically
- You'll never get the EADDRINUSE error again!
